VentureChat 3.8.0 adapted for **Paper 1.20.6** (PointForCraft build). Requires Java 21 on the server, as Paper 1.20.6 itself does.

## Fixes

- **Moderation GUI crash on 1.20.6.** Clicking a player in the `/vchatgui` inventory threw
  `IncompatibleClassChangeError: Found class org.bukkit.inventory.InventoryView, but interface was expected`.
  Upstream 3.8.0 is compiled against the 1.21.8 API, where `InventoryView` and `Sound` are interfaces.
  This build is compiled against paper-api 1.20.6.
- **Private message sound** no longer fails for the same reason (`Sound` is a class on 1.20.6).
- **Clickable chat on 1.20.6.** 3.8.0 always sent the 1.21.5 JSON keys (`click_event`, `hover_event`), which
  1.20.6 ignores, so links, the moderation GUI icon and placeholder click/hover actions did nothing.
  The format is now chosen by server version: `clickEvent`/`hoverEvent` before 1.21.5, the new keys from 1.21.5 on.
- Placeholder `open_url` click actions use the `url` key on 1.21.5+ (upstream sent `command`).

## Build

- GitHub Actions builds every branch, keeps a rolling `dev-build` pre-release from `master`, and publishes
  releases from `vX.Y.Z` tags.
- Fixed the upstream build: removed the dead Velocity snapshot repository, switched `bungeecord-api` to the
  1.20-R0.1 release from Maven Central, build with JDK 21, and updated Mockito for Java 21 tests.

## Install

Replace `VentureChat-3.8.0.jar` in `plugins/` with `VentureChat-3.8.1.jar` and restart. Config and player data are unchanged.
Dependencies are the same as upstream: Vault, ProtocolLib and PlaceholderAPI.
